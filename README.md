# Personal Portfolio Website

## Overview

This project is a personal portfolio website designed to introduce me as an aspiring software developer and showcase my skills, projects, and experience.

The website provides information about my background, highlights selected projects, and includes a contact form for visitors. It also incorporates interactive features to improve the user experience, including dark mode, a welcome modal, tooltips, and dynamically generated project cards.

## Technologies Used

The following languages and technologies were used to develop this portfolio:

- **HTML5** – Provides the structure and content of the website.
- **CSS3** – Handles page styling, layout, responsive elements, and dark mode appearance.
- **JavaScript** – Adds interactive functionality, DOM manipulation, form validation, and dynamic content generation.
- **JSON** – Used to convert project information into a format that can be stored.
- **Web Storage API (sessionStorage)** – Stores project information during the current browser session.

## Features

- Personal introduction and information section.
- Skills and technologies display.
- Featured educational resources and projects.
- Dynamically generated project cards using JavaScript objects and arrays.
- Session storage for maintaining project information during a browser session.
- Interactive dark mode toggle.
- Welcome modal displayed when the page loads.
- Contact form with input validation and interactive feedback.
- CSS tooltips and hover effects.


The website uses built-in browser technologies:

- HTML5
- CSS3
- JavaScript (ES6+)
- DOM API
- JSON
- Web Storage API


## Browser Compatibility

The website is intended to run in modern web browsers that support JavaScript, DOM manipulation, and the Web Storage API.
